# Community support

[Repository home](README.md) · [Documentation index](docs/README.md) · [Security policy](SECURITY.md)

Community support is public, best effort and has no response-time or availability SLA. Issues cover reproducible defects in the public installer, manifests, operator scripts and documented Community behavior. Use feature requests for scoped Community proposals and Discussions, if enabled, for general questions.

A useful bug report includes the JuggleCast version, host OS/architecture, Docker and Compose versions, Docker Control mode, sanitized `doctor.sh` result, reproduction steps, expected and actual results, and minimal redacted logs.

Never publish `.env`, licence keys, Icecast passwords, tokens, cookies, private URLs/IPs, machine names, private media, databases, backups or personal data. For a suspected vulnerability, do not open an issue: follow [private security reporting](SECURITY.md).
