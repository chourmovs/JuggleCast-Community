# JuggleCast brand guidelines

[Repository home](../README.md) · [Documentation index](README.md)

## Identity

JuggleCast should feel like a quiet nocturnal broadcast studio: precise, operator-led and illuminated by signal state rather than decoration. The waveform represents continuity and transitions; the red **ON AIR** state must be used only where broadcast state is meaningful.

## Palette

| Role | Hex | Use |
| --- | --- | --- |
| Background | `#080D18` | Hero and deep canvas |
| Surface | `#111827` | Panels |
| Cyan | `#22D3EE` | Primary signal |
| Violet | `#8B5CF6` | Transition/accent |
| On Air | `#F43F5E` | Live state only |
| Success | `#22C55E` | Healthy/ready state |
| Foreground | `#F8FAFC` | Primary type |
| Muted | `#94A3B8` | Secondary type |

Use foreground/background combinations with strong contrast. Future brand assets should include or preserve sufficient contrast so they remain legible in GitHub light and dark themes.

## Typography and future assets

Use the operating system UI sans-serif stack; do not bundle proprietary fonts or load CDN resources. No logo, hero, screenshot or social-preview binary is currently committed. Any future asset must be reviewed for accessibility, contrast, redistribution rights, GitHub rendering, light/dark compatibility and third-party trademark implications before publication.

## Voice

Be direct, technically factual and operator-centered. Say “self-hosted” and distinguish this MIT packaging/documentation repository from separately licensed OCI images. Never describe the complete product as open source unless every referenced component qualifies.

## Social preview

When maintainers can produce and review an official social preview outside this documentation-only change, use GitHub’s recommended dimensions, this palette and the short signature. Record its source and redistribution rights, avoid external resources, and upload it manually through repository settings rather than committing an unreviewed generated binary.
