# Licensing layers

[Repository home](../../README.md) · [Documentation index](../README.md)

| Element | Regime |
| --- | --- |
| Repository scripts and documentation | Repository [MIT licence](../../LICENSE) |
| JuggleCast Community OCI images | Licence declared in the published OCI metadata and release notices |
| Third-party dependencies | Their respective licences |
| Optional Pro functionality | Separate commercial licence |
| JuggleCast name, logo and identity | Separate trademark rights |

The MIT licence covers the packaging, scripts and documentation actually present in this repository; it does not automatically relicense downloaded service images. Image metadata and release notices govern each immutable image artifact. Libraries, runtimes and tools keep their upstream terms. Optional Pro rights, when offered, arise only from separate commercial terms. Copyright permission is also distinct from permission to use the JuggleCast marks; see [Trademarks](../../TRADEMARKS.md).

Do not describe the entire JuggleCast runtime as open source based solely on this public repository. Consult the relevant release's metadata and [third-party notices](../../THIRD_PARTY_NOTICES.md). This summary is informational and is not professional legal advice.
